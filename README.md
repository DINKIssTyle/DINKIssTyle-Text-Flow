# README

## About

This is the official Wails React-TS template.

You can configure the project by editing `wails.json`. More information about the project settings can be found
here: https://wails.io/docs/reference/project-config

## Live Development

To run in live development mode, run `wails dev` in the project directory. This will run a Vite development
server that will provide very fast hot reload of your frontend changes. If you want to develop in a browser
and have access to your Go methods, there is also a dev server that runs on http://localhost:34115. Connect
to this in your browser, and you can call your Go code from devtools.

## Building

Use the project build script so macOS Accessibility/TCC sees the app as the
same signed application between builds.

```bash
./build.sh --run
```

The script builds the Wails app, removes quarantine attributes, signs
`build/bin/DKST Text Flow.app` with the configured Apple Development identity,
verifies the signature, and can restart the app.

Bindings are generated by default. For a faster rebuild when Go bindings have
not changed:

```bash
./build.sh --skip-bindings --run
```

To inspect the current signature:

```bash
scripts/print-signature.sh
```

If you need a different signing identity:

```bash
DKST_CODESIGN_IDENTITY="Apple Development: Name (TEAMID)" ./build.sh --run
```
