# 소개
이 앱은 사용자가 텍스트 입력을 지원하기 위한 도구입니다.

- 자주 사용하는 스니펫에 단축키를 할당하여 빠른 텍스트 입력 가능.
- 작성 중인 텍스트를 선택하고 할당된 단축키를 누르면 **AI 지원**을 받습니다.

## 사용방법
### 용어
* **라벨**: 스니펫이 많을 때 라벨을 붙여 분리하여 관리할 수 있습니다.
* **스니펫**: 단축어로 삽입되는 텍스트 조각입니다.
---
### 스니펫 생성
1. 스니펫 라이브러리의 `+` 버튼을 클릭하면 새 스니펫 생성 창이 열립니다.
2. **단축어**에 입력한 키워드를 다른 곳에서 입력하면 해당 스니펫이 자동 완성됩니다.
   - **단축어는 로마자만 허용**합니다. `회사주소` 를 입력하고 싶다면 영문으로 `ghltkwnth'` 로 적으세요. 마지막 `'` 는 일반적인 텍스트 입력과 겹치지 않도록 합니다.
   - 단축어가 로마자로 되어 있어도, `회사주소'` 와 같이 **한글로 입력하면 작동**합니다.

> [!TIP] `ghltkwnth'` *끝 글자가 특수문자면 한글입력기 상태에서 호환성에 좋습니다.

       
3. 제목은 `회사주소`처럼 식별하기 좋게 작성하세요.
4. 내용에는 단축어로 입력될 실제 스니펫을 작성하세요.
   - 하단에 있는 단축어 확장 버튼을 사용하면 클립보드 내용을 함께 입력하거나, 현재 날짜나 시간을 입력할 수 있습니다.
     - 사용 예시 1: `<img src={{clipboard}}>`
     - 사용 예시 2: 시간 기본값인 `{{time:15:04}}` 형식을 `{{time:15 시 04 분}}` 으로 바꿀 수 있습니다.
     - 사용 예시 3: `Tab 키`로 이동 가능한 여러 필드에 한 번에 입력하려면, `탭 {{tab}}`를 이용합니다.
5. 확장방식:
   - **구분자**: 단축어가 입력되고 스페이스, 엔터 등으로 단축어를 벗어나면 스니펫이 입력됩니다.
   - **즉시**: 단축어가 완성되는 순간 스니펫이 입력됩니다.
6. 콘텐츠 유형:
   - 일반: 평문 텍스트를 처리합니다.
   - 서식있음: 구현예정
   - 이미지: 구현예정
7. 활성화: 이 스니펫을 활성화합니다. 체크를 해제하면 이 스니펫은 작동하지 않습니다.
8. 붙여넣기: 이 옵션을 활성화하면 유니코드 키 입력 대신 클립보드에서 복사한 내용을 붙여넣는 방식이 됩니다. 긴 스니펫에 유용합니다.
9. 대소문자 구분: 단축어의 대소문자를 구별하여 작동합니다.

---
### 라벨 관리
1. `전체` 라벨은 모든 스니펫을 표시합니다.
2. 라벨 우측의 `+` 버튼을 눌러 새 라벨을 추가합니다.
3. 이름, 색상 및 설명을 입력한 후 `라벨 저장`을 클릭합니다.
4. 분류할 스니펫을 선택하여 해당 라벨 위에 드래그하면 적용됩니다.

---

### 권장 LLM 모델
**3B~4B 크기의 LLM 모델**은 텍스트 어시스트 하기에 가볍고 빠릅니다.
- Gemma 4 E4B
- Qwen 3.5 4B

> [!caution] 추론 기능을 활성화하면 타임아웃 또는 처리 속도가 느려질 수 있습니다.

---

### 문제해결
- **단축어 뒤에 특수문자**를 붙이면 마크다운 밑줄 조합 방식의 한글 커밋에서 앞글자가 남는 문제를 방지할 수 있습니다.

  
- `회사이름` 이라는 `단축어`를 만들 때의 예시:
  - 한글 입력기 문제를 방지하는 경우: `ghltkdlfma'`
  - 잠재적 문제가 있는 경우: `ghltkdlfma`
